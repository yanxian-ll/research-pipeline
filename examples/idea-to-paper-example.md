```text
我有个 idea：用多模态大模型做遥感变化检测，帮我分析。
```

Suggested skill sequence:

```text
research-idea-refine
→ literature-grounding
→ gap-and-novelty-review
→ research-framework-design
→ experiment-planning
→ paper-core-writing
→ research-critic-review
```


```text

-> code-to-research-idea

-> gap-and-novelty-review
-> research-framework-design
-> experiment-planning
-> research-method-writing
-> evidence-based-writing
-> research-critic-review

```
