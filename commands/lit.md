# /lit

First classify scope.

- For independent paper reading, summaries, comparisons, or topic surveys, use
  `paper-reading-and-synthesis`.
- For closest work, novelty, baselines, or citations of a named idea/project,
  use `literature-grounding`.

Do not link independent literature work to the latest active project.

Required output depends on scope:

- Independent: verified reading notes or a cross-paper synthesis.
- Idea/project-linked: search queries, candidate papers, closest works, novelty
  risks, baselines/datasets, and next search round.
