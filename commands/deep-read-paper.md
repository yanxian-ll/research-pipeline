# /deep-read-paper

Use `paper-deep-reading`.

Start from the paper's desired capability, prior paradigm, concrete failure,
failed obvious fix, core contradiction, and design constraints. Derive each
major method component from that starting point, then audit supervision,
inference requirements, coordinate frames, experiments, tables, figures,
ablations, limitations, and unsupported arrows in the causal chain.

Default scope is independent. Link to an idea or project only when explicitly
requested.
