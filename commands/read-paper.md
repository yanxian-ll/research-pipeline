# /read-paper

Use `paper-reading-and-synthesis`.

Use `/deep-read-paper` and `paper-deep-reading` instead when the request asks
for 精读/深读, motivation-to-method derivation, detailed evidence auditing, or
reproduction-level understanding.

Default scope is independent. Link to an idea or project only when the user
explicitly names it or asks for related-work, novelty, baseline, method, or
experiment implications.

Required output: verified citation, problem, method, training, experiments,
findings, ablations, limitations, and synthesis requested by the user.
